# notebooks/

Exploration only. Nothing here counts.

A notebook is for finding something out. Once you have found it, **it moves into a
script** — `src/` for anything shared, `questions/<q>/analysis.py` for an answer — before
it becomes a number anyone else relies on.

Two reasons, and the second is the one that matters:

1. Notebooks run out of order and lie to you about it.
2. Every number on a slide has to be reproducible from a script. A judge asking "where
   does that come from" is answered with a file path, not with a cell that ran once on
   somebody's laptop in week two.
